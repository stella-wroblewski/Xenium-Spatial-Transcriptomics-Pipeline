# Xenium Single-Cell Spatial Transcriptomics Pipeline

This repository provides a template pipeline for processing, quality-checking, analyzing, and annotating single-cell Xenium data (10x Genomics) using **Seurat**, **Signac**, and **sc-type**. The workflow includes:

1. **Reading Xenium `.h5` files**  
2. **Creating Seurat objects**  
3. **Quality Control (QC) filtering**  
4. **SCTransform normalization**  
5. **Dimensionality reduction (PCA, UMAP)**  
6. **Clustering and subsetting**  
7. **Differential expression (DE)**  
8. **Cell-type annotation**  
9. **Functional enrichment (GO, KEGG)**  

This guide walks you through each stage of the analysis.

## Detailed Steps

The pipeline is organized into logical sections:

### 1. Load Libraries
You’ll need **Seurat**, **Signac**, **dplyr**, **ggplot2**, **openxlsx**, **HGNChelper**, and optionally **clusterProfiler** for downstream analysis.  
```r
library(Seurat)
library(Signac)
library(dplyr)
library(ggplot2)
library(tibble)
library(openxlsx)
library(HGNChelper)
```

### 2. Source sc-type Functions
This pipeline uses **sc-type** for cell-type annotation. The relevant functions (`gene_sets_prepare.R` and `sctype_score_.R`) are sourced from GitHub:
```r
source("https://raw.githubusercontent.com/IanevskiAleksandr/sc-type/master/R/gene_sets_prepare.R")
source("https://raw.githubusercontent.com/IanevskiAleksandr/sc-type/master/R/sctype_score_.R")
```
*Note: If the URLs change or become unavailable, host these scripts locally and update the source paths.*

```r

```
- **QC parameters**: Default thresholds (e.g., `nCount_RNA > 500 & percent.mt < 15`) can be adjusted based on your data.

### 4. Merge Multiple Samples (Optional)
If you have multiple samples, you can merge them with `merge()`. After merging, you can re-run **SCTransform**, **RunPCA**, and **RunUMAP** on the combined object.

### 5. Define Groups & Differential Expression
If you have two (or more) conditions (e.g., **Control** vs. **Treated**), define them in the `Seurat` object’s metadata (`combined$group <- ...`), then use:
```r
Idents(combined) <- "group"
FindMarkers(..., test.use = "wilcox")
```
Adjust thresholds for `logfc.threshold` and `min.pct` as needed.  

### 6. Cell-Type Annotation with sc-type
- **Prepare** gene sets from sc-type’s database:  
  ```r
  gs_list <- gene_sets_prepare("ScTypeDB_short.xlsx", "Brain")
  ```
- **Score** each cell with `sctype_score()` and assign the highest-scoring cell type:
  ```r
  es.max <- sctype_score(scRNAseqData = as.matrix(...))
  combined$cell_type <- apply(es.max, 2, function(x) rownames(es.max)[which.max(x)])
  ```
- **Visualize** with `DimPlot(..., group.by = "cell_type")`.

### 7. Subset & Re-Cluster Specific Populations
If you want to focus on, say, **microglial cells**, subset them:
```r
microglia_obj <- subset(combined, subset = cell_type == "Microglial cells")
```
Then re-run **SCTransform**, **PCA**, **UMAP**, **FindClusters**, etc., to examine sub-clusters within that cell type.

### 8. GO/KEGG Enrichment (clusterProfiler)
- **Identify** significant genes (e.g., from DE results or marker genes).  
- **Convert** gene SYMBOLs to ENTREZ IDs:  
  ```r
  gene_ids <- bitr(sig_genes, fromType = "SYMBOL", toType = "ENTREZID", OrgDb = org.Mm.eg.db)
  ```
- **Run** `enrichGO()` and `enrichKEGG()` to see which pathways are overrepresented.  
- **Visualize** or export to CSV.

## Customization & Notes

1. **QC Thresholds**: Tailor the minimum UMI, mitochondrial gene percentage, and other filtering criteria to your dataset.  
2. **Number of PCs**: Adjust the number of PCs used in PCA/UMAP if you see suboptimal clustering or excessive noise.  
3. **Clustering Resolution**: Use different resolutions (e.g., 0.1–1.0) in `FindClusters` for finer or coarser clustering.  
4. **sc-type Tissue**: If you’re not analyzing brain tissue, replace `"Brain"` with another label (or supply your own marker lists).  
5. **Human vs. Mouse Genes**: If working with human data, use `org.Hs.eg.db` instead of `org.Mm.eg.db` in clusterProfiler steps. Also adjust your QC pattern for mitochondrial genes (`^MT-` might differ based on your gene naming conventions).  
6. **Output Files**: The pipeline demonstrates saving CSV files for differential expression (`final_df`) and functional enrichment results. Adjust filenames/paths as you like.
